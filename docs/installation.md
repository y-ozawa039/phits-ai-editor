# PHITS AI Editorのインストールと初期設定

日本語 | [English](installation.en.md)

この文書は、Windows 11 x64向け`0.0.1-alpha`配布物の利用者向けガイドです。
PHITS AI Editorは個人開発のalpha版であり、重要な入力ファイルは事前にバックアップして
ください。

## 1. どのファイルをダウンロードするか

| 配布物 | 推奨する利用者 | Windowsへの登録 |
| --- | --- | --- |
| `PHITS-AI-Editor-v0.0.1-alpha-windows-x64-setup.exe` | 通常利用する方 | あり |
| `PHITS-AI-Editor-v0.0.1-alpha-windows-x64-portable.zip` | 試用、複数版の比較、開発・調査をする方 | なし |

通常はインストーラーを推奨します。GitHubが自動表示する`Source code (zip)`は
Windows用ポータブル版ではありません。また、裸の`phits-ai-editor.exe`だけを取り出して
起動することはできますが、ライセンス、既知の問題、ビルド情報などが伴わないため、
配布・保管にはポータブルZIPを使用してください。

## 2. 事前に用意するもの

- Windows 11 x64
- PHITS本体（編集だけなら未設定でも起動可能）
- AI支援を使用する場合のみ、Codex CLIと有効な認証
- インストーラーがWebView2を取得する必要がある環境では、インターネット接続

PHITS、Codex CLI、認証情報、MPI・OpenMP環境は本アプリへ同梱されません。本アプリは
システムの`PATH`や`PHITSPATH`を変更しません。

## 3. インストーラー版

1. GitHub Releaseから`...windows-x64-setup.exe`と`SHA256SUMS.txt`を取得します。
2. 後述の方法でSHA-256を照合します。
3. PHITS AI Editorを終了してからインストーラーを実行します。
4. インストール後、スタートメニューからPHITS AI Editorを起動します。

現在のインストーラーは、管理者権限を原則必要としない「現在のユーザー」方式です。
アプリを`%LOCALAPPDATA%`配下へ配置し、次のWindows統合を行います。

- スタートメニューへの登録
- Windowsの「インストールされているアプリ」への登録
- アンインストーラーの作成
- `.inp`および`.pht`を開けるアプリとして登録
- LICENSE、NOTICE、第三者ライセンス、リリースノートなどの配置

既存のファイル関連付けやWindowsの状態によっては、インストール後に「プログラムから
開く」でPHITS AI Editorを一度選ぶ必要があります。Explorerのアイコン表示には、
ExplorerまたはWindowsの再起動が必要になる場合があります。

## 4. ポータブル版

1. GitHub Releaseから`...windows-x64-portable.zip`と`SHA256SUMS.txt`を取得します。
2. SHA-256を照合してから、書き込み可能な専用フォルダーへZIP全体を展開します。
3. 展開したフォルダー内の`phits-ai-editor.exe`を起動します。

ZIP内の文書やSBOMは削除せず、実行ファイルと一緒に保管してください。ポータブル版は
スタートメニュー、Windowsのアプリ一覧、ファイル関連付け、アンインストーラーを作成
しません。不要になった場合はアプリを終了し、展開したフォルダーを削除できます。

## 5. 初回起動後の設定

### PHITS

1. 上部メニューの「設定」を開きます。
2. 「PHITS実行環境」を選びます。
3. 自動検出結果を確認するか、PHITSのルートフォルダーを指定します。
4. 「設定を保存して確認」を押します。

アプリ全体の設定より、ワークスペース内の`.phits-editor/workspace.json`にある設定が
優先されます。MPI・OpenMPを利用する場合は、PHITS側の正規の手順で実行環境を準備して
ください。

### Codex

AI支援を利用する場合は、[OpenAI公式のCodex CLIガイド](https://developers.openai.com/codex/cli)
に従ってCodex CLIを別途インストールし、認証を済ませてください。
エディタは起動時にApp Server互換性を確認し、会話、スレッド、ファイル編集、承認の
利用可否を表示します。CodexがなくてもPHITSの編集・実行機能は利用できます。

## 6. `.inp`／`.pht`を直接開く

インストーラー版では、Explorerで対象ファイルをダブルクリックするか、右クリックして
「プログラムから開く」からPHITS AI Editorを選べます。ファイルの親フォルダーが
ワークスペースになり、そのファイルがPHITS実行対象として選択されます。

ポータブル版では、次のいずれかを利用できます。

- ファイルを`phits-ai-editor.exe`へドラッグ＆ドロップする
- 「プログラムから開く」で展開先の`phits-ai-editor.exe`を指定する
- アプリを起動してからワークスペースを開く

## 7. SmartScreen警告

`0.0.1-alpha`はコード署名されていないため、Windows SmartScreenが警告を表示する
可能性があります。公式GitHub Release以外から取得したファイルや、SHA-256が一致しない
ファイルは実行しないでください。配布元とハッシュを確認できた場合に限り、警告内容を
読んだうえで利用者自身が実行を判断してください。

PowerShellでは次のように確認できます。

```powershell
Get-FileHash .\PHITS-AI-Editor-v0.0.1-alpha-windows-x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

表示されたハッシュが`SHA256SUMS.txt`の同じファイル名の値と完全に一致することを確認
します。大文字・小文字の違いは問題ありません。

## 8. 更新

alpha版には自動更新機能がありません。新しいリリースを手動で取得してください。

- インストーラー版：アプリを終了し、新しいインストーラーを実行します。
- ポータブル版：新しい専用フォルダーへ展開し、動作確認後に旧版を整理します。

リリースごとにSHA-256を確認し、重要な入力ファイルをバックアップしてください。

## 9. アンインストール

インストーラー版は、Windowsの「設定 → アプリ → インストールされているアプリ」から
PHITS AI Editorをアンインストールできます。アプリ本体、登録情報、ショートカット、
ファイル関連付けが削除対象になります。

アンインストールは、PHITS本体、Codex CLI、ワークスペース、`.inp`／`.pht`、PHITS出力、
ワークスペース内の`.phits-editor`を削除しません。また、現在のalpha版はAppData内の
表示設定、PHITSパス設定、WebViewデータなどが完全に削除されることを保証しません。
完全な初期化方法は、保存場所を確認したうえで将来の版で整備する予定です。

## 10. 問題を報告する前に

- [既知の問題](known-issues-v0.0.1-alpha.md)を確認してください。
- バージョン、Windowsの版、再現手順、期待した結果、実際の結果を記録してください。
- 認証情報、個人情報、未公開研究データ、再配布できないPHITS資料はIssueへ載せないで
  ください。
- セキュリティ問題は公開Issueではなく、[セキュリティポリシー](../SECURITY.md)に従って
  報告してください。

このalpha版は、自力でログやソースを調査し、回避・復旧を進められる方を主な対象と
しています。個別サポートや回答期限は保証されません。
