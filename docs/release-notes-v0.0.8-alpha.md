# PHITS AI Editor 0.0.8-alpha

日本語 | [English](release-notes-v0.0.8-alpha.en.md)

`0.0.8-alpha`では、Sandboxの問題を診断して利用者の判断を助ける役割と、端末全体の
設定を変更する役割を分離しました。PHITS AI Editorは診断と案内に徹し、Codexの
Sandbox設定やWindowsのセキュリティ設定を直接変更しません。

## 主な変更

- 自動診断で書込みを確認できない場合、現在のモデル・思考で、専用の一時ファイルだけを変更する
  任意の実編集診断を開始できます。作成・1行の書換え・削除を開始前に説明し、「検査を開始」を
  選んだ後は、Rustが対象を照合した診断用ファイル変更だけを自動承認します。同じ変更を確認する
  追加の承認カードは表示しません。
- 実編集診断に成功した場合は同じ接続中だけ編集を有効にします。利用者が明示的に選んだ場合は、
  **診断結果にかかわらず編集を許可**から、診断結果に基づくエディタ側の制限だけを現在の
  ワークスペースと接続中に限って解除できます。
  どちらもSandbox、承認設定、ワークスペース境界、PHITS実行検証を変更しません。
- Codexへ接続できない場合は、診断用の相談文をChatGPTデスクトップ版のローカルCodexタスクへ
  貼り付ける案内を表示します。
- エディタから`elevated`／`unelevated`の再セットアップを開始するボタンを削除しました。
  ローカルユーザー、ファイアウォール、ローカルポリシー、所有権、アクセス規則を
  エディタが変更することはありません。
- フォルダー固有のアクセス問題では、端末全体の設定変更を案内せず、診断結果、相談文、
  再診断によって原因を切り分けます。
- 生成AIへの相談文には、まず読み取り専用の調査を行い、変更が必要な場合は影響と
  元に戻す方法を説明して利用者の判断を求めるよう明記しました。
- **ヘルプ > 診断情報の詳細…**の**ログフォルダーを開く**を、バックエンドが管理する
  固定の起動ログ保存場所だけを開く方式へ変更しました。
- GitHub ActionsのWindowsテスト成果物には、アプリのバージョンとコミットIDを含む
  名前を付け、正式なGitHub Releaseと区別しやすくしました。

## プライバシーと安全境界

診断結果はキャッシュしません。Codex接続時と手動再診断時に現在の環境を検査します。
診断レポートでパスから利用者名を伏せても、相対フォルダー名や自由記述に個人情報が
残る可能性があります。外部へ共有する場合は内容をよく確認してください。
