# 0.0.5-alphaの既知の問題と制限

日本語 | [English](known-issues-v0.0.5-alpha.en.md)

- Windows 11 x64向けの未署名alpha版です。SmartScreenが警告する場合があります。
- PHITS、Codex CLI、MPI/OpenMP環境、各ライセンスは利用者が用意してください。
- Codexから要求できるのはPHITSの通常実行だけです。計算優先実行はツールバーから
  明示的に開始してください。ANGEL、DCHAIN、PHIG-3DのCodex直接実行はできません。
- `run_phits`は現在選択中で保存済みの`.inp`／`.pht`だけを受理します。未保存内容を
  実行したり、別の入力を暗黙に選択したりしません。
- PHITSが終了するまでCodexターンは実行結果を待ちます。長時間計算では、必要に応じて
  エディタの停止操作または計算優先実行を利用してください。
- 一時的なローカルMCPサーバーは現在のCodex接続だけに追加され、利用者のグローバル
  Codex設定を書き換えません。Codex CLI側のMCP互換性が失われた場合、この機能だけが
  利用できない可能性があります。
- 自律モードで許可されたファイル変更も、通常のCodex変更履歴と差分確認に記録されます。
- アンインストールしてもPHITS、Codex CLI、ワークスペース、入力・出力は削除しません。
