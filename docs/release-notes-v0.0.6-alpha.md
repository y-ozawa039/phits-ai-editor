# PHITS AI Editor 0.0.6-alpha

日本語 | [English](release-notes-v0.0.6-alpha.en.md)

`0.0.6-alpha`では、未知のWindows環境で問題を切り分けやすくするため、Codex編集環境の
実動作診断、保存場所の確認、診断レポート、起動ログを整備しました。

## 主な変更

- Sandbox内のコマンド実行に加え、ワークスペース直下への新規作成、既存相当ファイルの変更、
  子フォルダーへの作成、フォルダーのアクセス規則を分けて診断します。
- 通常のワークスペース境界で失敗した場合は、権限を広げずに直接指定による補助検査を行い、
  Sandbox全体の問題とフォルダー固有の問題を区別しやすくしました。
- Sandboxの再セットアップが有効と考えられる場合だけ、明示操作のボタンを表示します。
- ドライブ種別、ファイルシステム、UNC、特殊フォルダー、読み取り専用属性、パス長、
  OneDrive同期対象を、ワークスペースを再帰走査せずに確認します。
- 文字化けしやすいWindowsコマンド出力をUnicodeとして扱い、長い診断結果をスクロールして
  確認できるようにしました。
- 問題発生時の警告または**ヘルプ > 診断レポートを保存…**から、環境情報をMarkdownで
  保存できます。初期設定では利用者名や作業フォルダー等の既知のパスを伏せます。
- **ヘルプ > 診断情報の詳細…**で起動ログの保存場所と保持方法を確認できます。起動ログは
  256 KiBを上限とし、1世代だけローテーションします。
- 診断結果はキャッシュせず、起動、ワークスペース変更、Codex接続、手動再診断の各時点で
  必要な検査をやり直します。
- 診断ダイアログと設定ダイアログへ初期フォーカスを移し、Escキーで閉じられるようにしました。
- 再現用のSandbox診断シナリオを追加し、Windows CIで検査します。

## プライバシーと安全境界

起動ログにはワークスペースのパス、入力ファイルの内容、認証情報を記録しません。接続失敗は
分類だけを記録し、詳細なエラー本文は起動ログへ残しません。診断レポートのパス伏せは既知の
ローカルパスを置き換えますが、エラーメッセージやフォルダー名に個人情報が含まれる可能性が
あります。外部へ共有する場合は内容をよく確認してください。

診断は権限を自動で拡張しません。Codexのファイル操作とPHITS実行には、`0.0.5-alpha`で
導入した承認モードとエディタ所有の検証済み実行経路を引き続き使用します。
