# PHITS AI Editor 0.0.4-alpha

日本語 | [English](release-notes-v0.0.4-alpha.en.md)

`0.0.4-alpha`は、CodexのSandbox実動作診断を実際のワークスペース構成へ
適応させ、診断表示とファイル編集操作を改善するalpha更新です。

## どのファイルをダウンロードするか

- 通常利用には`PHITS-AI-Editor-v0.0.4-alpha-windows-x64-setup.exe`を使用してください。
- 試用、複数版の比較、開発・調査には
  `PHITS-AI-Editor-v0.0.4-alpha-windows-x64-portable.zip`を展開して使用してください。
- GitHubが自動生成する`Source code (zip)`はWindows用ポータブルアプリではありません。

実行前に`SHA256SUMS.txt`で配布物を照合してください。

## 変更点

- Codexが明示的な書込みルート構成を受け付けない場合、Sandboxを解除せずに
  ワークスペース書込み診断を安全な代替構成で再試行します。これにより、PHITSと
  ワークスペースが異なるドライブにある環境での誤警告を抑制します。
- 画面上の名称をWindows標準機能と混同しにくい「Sandbox」へ変更しました。
  詳細診断にはCodexが実際に使用している方式（`elevated`／`unelevated`など）と、
  組織ポリシーで許可された方式を表示します。
- 診断用の生成AI相談文から、Windows標準の「Windows Sandbox」を有効化すれば
  解決すると決めつける表現を除き、実動作結果に基づく切り分けを案内します。
- Codexが新しいファイルを生成した場合、差分確認の対象ファイルをエディターの
  タブとして開き、差分を閉じた後も生成ファイルへ移動しやすくしました。
- エクスプローラーパネルの幅をドラッグで変更できるようにし、設定した幅を保存します。
  境界をダブルクリックすると初期幅へ戻ります。
- 出力欄は追加された行へ自動的に追従します。利用者が上へスクロールすると追従を
  一時停止し、末尾へ戻ると再開します。
- GitHub ActionsのクリーンなWindows環境で、検査、ポータブル版・NSIS
  インストーラー生成、SBOM・SHA-256生成を行う手動リリースビルドを追加しました。

## 安全設計と対象範囲

CodexからPHITS、ANGEL、DCHAIN、PHIG-3Dを直接実行することは、引き続き安全境界で
禁止しています。PHITSの計算にはエディタ上部の「通常実行」または「計算優先実行」を
使用してください。

公式バイナリ対象はWindows 11 x64です。PHITS本体、Codex CLI、認証情報は同梱しません。
コード署名されていないalpha版のため、Windows SmartScreenが警告を表示する場合が
あります。重要な入力ファイルは必ずバックアップしてください。

詳細は[インストールガイド](installation.md)と
[既知の問題](known-issues-v0.0.4-alpha.md)を参照してください。
