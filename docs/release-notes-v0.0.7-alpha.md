# PHITS AI Editor 0.0.7-alpha

日本語 | [English](release-notes-v0.0.7-alpha.en.md)

`0.0.7-alpha`では、Codex App ServerのSchemaが利用可能であっても、現在のワークスペースで
実際に書込みできない状態を編集可能として扱わないよう、Sandbox診断と編集モードを連動させました。

## 主な変更

- Sandbox診断では、明示した書込みルートを使う方式を先に検査し、その方式に対応しない環境では
  現在の作業フォルダーを基準にする方式も検査します。
- コマンド実行、ワークスペース直下への作成、既存相当ファイルの変更、子フォルダーへの作成の
  全項目に成功した書込み方針だけを、同じCodex接続の通常ターンへ引き継ぎます。
- 実書込みを確認できない接続では、「アクションの承認」を相談専用に固定します。フロントエンドの
  表示だけでなく、Rust側でも書込み可能なターンを開始しません。
- `unelevated`方式で書込みを確認できない場合は、組織ポリシーで許可されていれば
  **elevatedで再セットアップ（推奨）**と**unelevatedで再セットアップ**を選べます。
- 再セットアップにはCodex App Serverの公式要求を使います。エディタがフォルダーのアクセス規則を
  再帰的に変更したり、所有権を取得したり、Sandboxを解除したりすることはありません。
- パスを伏せる診断レポートでは、エラー表示の途中で空白が挿入された既知のパスと、検出可能な
  その他のローカル絶対パスも置換します。

## プライバシーと安全境界

診断レポートのパス伏せを選んでも、相対フォルダー名や自由記述に個人情報が残る可能性があります。
外部へ共有する場合は内容をよく確認してください。診断結果は引き続きキャッシュせず、Sandboxの
実動作検査はCodex接続時と手動再診断時に行います。
