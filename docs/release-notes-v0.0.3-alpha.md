# PHITS AI Editor 0.0.3-alpha

日本語 | [English](release-notes-v0.0.3-alpha.en.md)

`0.0.3-alpha`は、Codexとの接続確認に加えて、Windows Sandbox内で実際に
コマンドを実行し、現在のワークスペースへ書き込めるかを診断するalpha更新です。

## どのファイルをダウンロードするか

- 通常利用には`PHITS-AI-Editor-v0.0.3-alpha-windows-x64-setup.exe`を使用してください。
- 試用、複数版の比較、開発・調査には
  `PHITS-AI-Editor-v0.0.3-alpha-windows-x64-portable.zip`を展開して使用してください。
- GitHubが自動生成する`Source code (zip)`はWindows用ポータブルアプリではありません。

実行前に`SHA256SUMS.txt`で配布物を照合してください。

## 変更点

- Codex App Serverへの接続、Windows Sandboxの準備状態、Sandbox内でのコマンド実行、
  現在のワークスペースへの書き込みを個別に診断します。
- 実動作診断ではモデルを呼び出さず、ワークスペース内へ一時的な検査ファイルを書き込み、
  内容を確認してから削除します。PHITS計算は実行しません。
- 診断結果を画面左下の「実行環境」に統合し、問題がない場合はCodexパネルの表示領域を
  占有しません。問題がある場合だけ、既存のCodex診断案内へ警告を追加します。
- 「検査したファイルと理由」および「生成AIへの相談文を表示」から、判定根拠と
  自己解決用の相談文を確認できます。
- 「Codex入力欄へ挿入」を押した時に利用可能なスレッドがなければ、新しい相談用
  スレッドを作成してから文章を挿入します。文章は自動送信しません。
- 出力欄を末尾へ自動スクロールします。利用者が上へスクロールすると追従を一時停止し、
  末尾へ戻ると自動追従を再開します。
- `0.0.2-alpha`で追加したPHITS用Codex設定の詳細診断も引き続き利用できます。

## 安全設計と対象範囲

CodexからPHITS、ANGEL、DCHAIN、PHIG-3Dを直接実行することは、引き続き安全境界で
禁止しています。PHITSの計算にはエディタ上部の「通常実行」または「計算優先実行」を
使用してください。

公式バイナリ対象はWindows 11 x64です。PHITS本体、Codex CLI、認証情報は同梱しません。
コード署名されていないalpha版のため、Windows SmartScreenが警告を表示する場合が
あります。重要な入力ファイルは必ずバックアップしてください。

詳細は[インストールガイド](installation.md)と
[既知の問題](known-issues-v0.0.3-alpha.md)を参照してください。
