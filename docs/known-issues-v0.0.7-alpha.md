# 0.0.7-alphaの既知の問題と制限

日本語 | [English](known-issues-v0.0.7-alpha.en.md)

- Windows 11 x64向けの未署名alpha版です。SmartScreenが警告する場合があります。
- PHITS、Codex CLI、MPI/OpenMP環境、各ライセンスは利用者が用意してください。
- Sandbox再セットアップで、組織ポリシー、セキュリティソフト、既存フォルダー固有の制限を
  必ず解消できるわけではありません。エディタはアクセス規則や所有権を直接変更しません。
- 実書込みを確認できない場合もCodexとの会話は利用できますが、ファイル編集とCodexからの
  PHITS実行は相談専用モードでは実行されません。ツールバーからのPHITS実行は別経路です。
- 診断用の一時ファイルと子フォルダーは検査後に削除します。異常終了した場合は、
  `.phits-editor-codex-`で始まる検査項目が残る可能性があります。
- パスを伏せた診断レポートでも、相対フォルダー名や自由記述に個人情報が残る場合があります。
  外部へ共有する前に内容を確認してください。
- Codexから要求できるのはPHITSの通常実行だけです。計算優先実行はツールバーから
  明示的に開始してください。ANGEL、DCHAIN、PHIG-3DのCodex直接実行はできません。
- `run_phits`は現在選択中で保存済みの`.inp`／`.pht`だけを受理します。
- アンインストールしてもPHITS、Codex CLI、ワークスペース、入力・出力は削除しません。
