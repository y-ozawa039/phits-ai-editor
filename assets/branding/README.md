# Branding source

`phits-ai-editor-logo.png` is the 2008 × 2008 master raster source for the
provisional PHITS AI Editor alpha logo. It was created by and is copyright
2026 Yohei Ozawa. It is not derived from the PHITS, JAEA, OpenAI, or Codex
logos.

Generated Tauri icons are stored under `src-tauri/icons/`. The project uses the
logo according to [`TRADEMARKS.md`](../../TRADEMARKS.md). Do not place the only
source copy under `src-tauri/target/`; that directory is ignored build output.
