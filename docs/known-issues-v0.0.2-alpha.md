# 0.0.2-alphaの既知の問題と制限

日本語 | [English](known-issues-v0.0.2-alpha.en.md)

- 公式バイナリはWindows 11 x64だけを対象とします。Windows 10およびLinuxは、
  サポート対象の配布物として受入を完了していません。
- ビルドは署名されていないため、Windows SmartScreenが警告を表示する場合があります。
- PHITS、Codex CLI、MPI/OpenMPの前提環境とライセンスは利用者が用意してください。
- PHITS用Codex設定の検査は、設定ファイルを静的に読み取る診断です。App Serverが
  実際に指示を読み込んだことまでは確認できません。
- Codex App Server互換性の基準は0.153.1です。新しいCLIは機能単位で検査し、
  Schemaを確認するまでは制限モードで動作する場合があります。
- alpha版に自動更新機能はありません。新しいリリースを手動で導入してください。
- アンインストールしてもPHITS、Codex CLI、ワークスペース、PHITS入出力、
  `.phits-editor`メタデータは削除しません。
- alpha期間中にインターフェース、暫定的な製品名、ロゴを変更する場合があります。
- 個別の環境構築支援、Issueへの回答期限、Forkの後方互換性は保証しません。

再現可能な問題は、認証情報、個人情報、非公開研究データ、再配布できないPHITS資料を
除去してからGitHub Issueへ報告してください。脆弱性は
[セキュリティポリシー](../SECURITY.md)に従って非公開で報告してください。
